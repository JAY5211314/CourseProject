# 游戏数据分析系统 - 整体设计方案

## 1. 项目概述

**项目名称**: 游戏数据分析与预测系统
**核心功能**: 从游戏平台爬取游戏数据，使用机器学习进行聚类分析和回归预测，并可视化展示结果
**目标用户**: 游戏数据分析爱好者、研究人员

## 4. 机器学习方法

### 4.1 KMeans聚类
**原理**: 将数据划分为K个簇，使得簇内方差最小

**步骤**:
1. 选择K个初始质心
2. 计算每个点到各质心的距离
3. 将点分配到最近的簇
4. 更新质心为簇内均值
5. 重复直到收敛

**评估指标**:
- 轮廓系数 (Silhouette Score)
- 簇内平方和 (Inertia)

### 4.2 线性回归
**原理**: 建立评分与评论数的线性关系

**模型**: rating = α + β × log(commentCount) + ε**模型**:rating = α β × log(commentCount) &epsilon；

**评估指标**:
- R² 决定系数
- MSE 均方误差
- RMSE 均方根误差

### 4.3 特征重要性
使用随机森林计算各特征对评分预测的贡献度

## 5. 可视化方案

### 5.1 聚类散点图
- X轴: 评论数 (对数刻度)
- Y轴: 游戏评分
- 颜色: 聚类标签
- 大小: 玩家数量

### 5.2 特征重要性图
- 柱状图展示各特征贡献度
- 包含: 评论数、标签数、分类等

### 5.3 回归拟合图
- 散点图 + 回归线
- 展示预测值与实际值对比

### 5.4 标签词云图
- 展示热门游戏标签分布

## 6. AI智能体辅助开发

### 6.1 扣子平台
- **数据分析Bot**: 解读ML结果，提供洞察建议
- **数据采集Bot**: 辅助生成爬虫规则
- **可视化Bot**: 自动生成图表配置

### 6.2 CodeBuddy
- 代码补全和优化建议
- Bug自动检测和修复

### 6.3 辅助环节示例
1. **数据清洗**: AI辅助识别异常值和缺失数据
2. **参数调优**: AI推荐最优K值和回归参数
3. **结果解读**: AI生成数据分析报告摘要

## 7. 系统模块划分

- `components/FeatureChart`: 特征重要性图表

### 后端模块
- `controllers/game.controller.ts`: 游戏数据接口
- `services/crawler.service.ts`: 爬虫服务
- `services/ml.service.ts`: 机器学习服务
- `services/chart.service.ts`: 可视化服务
